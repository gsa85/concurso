1. Motores de Busca (Search Engines)

São sistemas que rastreiam a internet e indexam páginas para que o usuário possa encontrá-las por meio de palavras-chave.

Principais Motores:

  • Google: O mais utilizado no mundo. Possui o algoritmo de busca mais avançado e oferece diversos serviços integrados (Gmail, Drive, Maps).
  • Bing: Motor de busca da Microsoft. É o padrão no navegador Edge e no Windows.
  • Yahoo!: Um dos mais antigos, hoje utiliza a tecnologia do Bing para os resultados de busca.
  • DuckDuckGo: Focado na privacidade. Ele não rastreia as pesquisas do usuário e não cria perfis de navegação.

⚠️ Pegadinha FAFIPA: As aspas duplas " " são o operador mais cobrado. Elas servem para buscar a frase exata. Se você digitar concurso público sem aspas, o Google pode retornar páginas que tenham apenas "concurso" ou apenas "público". Com aspas, ele busca a expressão exata.

3. Surface Web, Deep Web e Dark Web

  • Surface Web (Web de Superfície): É a parte da internet que é indexada pelos motores de busca (Google, Bing). É o que acessamos normalmente.
  • Deep Web (Web Profunda): É a parte da internet que NÃO é indexada pelos motores de busca. Inclui sites de bancos, e-mails, intranets de empresas e bases de dados acadêmicos. Não é ilegal, é apenas conteúdo privado ou restrito.
  • Dark Web (Web Escura): É uma pequena parte da Deep Web que exige softwares específicos (como o Tor) para ser acessada. É frequentemente associada a atividades ilegais (comércio de drogas, armas, etc.).
⚠️ Pegadinha FAFIPA: A Deep Web NÃO é a mesma coisa que a Dark Web. A Deep Web é a maior parte da internet (conteúdo privado). A Dark Web é uma pequena fração, acessível apenas com ferramentas específicas (Tor), geralmente associada a ilegalidades.

💡 Dicas de Ouro para a Prova

⚠️ O que a FAFIPA adora cobrar:

  • Aspas (" "): Busca a frase exata.
  • Menos (-): Exclui a palavra da busca.
  • site: Busca apenas dentro de um site específico (ex: site:gov.br).
  • filetype: Busca por tipo de arquivo (ex: filetype:pdf).
  • DuckDuckGo: Focado em privacidade, não rastreia o usuário.
  • Deep Web: Conteúdo não indexado (e-mails, intranets, bancos). Não é sinônimo de ilegalidade.
  • Dark Web: Exige Tor, associada a conteúdo ilegal.
