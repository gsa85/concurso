1. O que é Software?

Software é a parte lógica do computador. São os programas, instruções e dados que o hardware executa. Diferente do hardware, você não pode tocar no software.

Os softwares são divididos basicamente em três categorias: Básico, Aplicativo e Utilitário.

2. Software Básico

É o software essencial para o funcionamento do computador. Sem ele, a máquina não liga ou não funciona corretamente.

Principais exemplos:

  • Sistemas Operacionais: Windows, Linux, macOS, Android, iOS. São responsáveis por gerenciar o hardware e permitir a execução de outros programas.
  • Drivers (Controladores): Programas que permitem a comunicação entre o sistema operacional e os hardwares (ex: driver da impressora, driver de vídeo).
  • BIOS/UEFI: Software gravado na memória ROM que inicializa o computador.

3. Software Aplicativo

São os programas que o usuário utiliza para realizar tarefas específicas. São os softwares "do dia a dia".

Principais exemplos:

  • Editores de texto: Word, Google Docs.
  • Planilhas: Excel, Google Sheets.
  • Navegadores: Chrome, Firefox, Edge.
  • Comunicadores: WhatsApp, Telegram.
  • Jogos: Qualquer jogo instalado no PC.

4. Software Utilitário

São programas que auxiliam na manutenção, segurança e otimização do sistema. Não são essenciais para ligar a máquina, mas ajudam a mantê-la saudável.

Principais exemplos:

  • Antivírus: Avast, Kaspersky, Windows Defender.
  • Compactadores de arquivos: WinRAR, 7-Zip (compactam e descompactam arquivos).
  • Limpadores de disco: CCleaner.
  • Backup: Programas de cópia de segurança.
  • Desfragmentadores de disco: Ferramentas para organizar o HD.
⚠️ Pegadinha FAFIPA: O Windows é Software Básico (Sistema Operacional). O Word é Software Aplicativo. O Antivírus é Software Utilitário. A banca vai trocar as classificações.

💡 Dicas de Ouro para a Prova

⚠️ O que a FAFIPA adora cobrar:

  • Software Básico vs. Aplicativo: O Windows é básico (essencial). O Word é aplicativo (tarefa específica).
  • Utilitário: Antivírus e compactadores (WinRAR) são utilitários, não aplicativos.
  • Driver: É o software que faz a ponte entre o sistema operacional e o hardware (ex: driver da impressora).
  • BIOS: É um software básico gravado na memória ROM (não volátil).
