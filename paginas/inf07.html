1. Windows 10 e Windows 11

O Windows é um software básico (sistema operacional) proprietário, desenvolvido pela Microsoft. É o sistema mais utilizado em computadores pessoais.

Principais Recursos (Windows 10 e 11)

  • Menu Iniciar: O ícone do Windows (tecla Windows) abre o menu com os programas instalados e a opção de desligar.
  • Barra de Tarefas: Fica na parte inferior da tela. Exibe os programas abertos, o relógio e a área de notificação.
  • Área de Trabalho (Desktop): É a tela principal, onde ficam os ícones de atalho.
  • Explorador de Arquivos: É o gerenciador de arquivos do Windows. Aberto com o atalho Windows + E.
  • Windows Update: Ferramenta de atualização do sistema. Mantém o Windows seguro e atualizado.
  • Painel de Controle / Configurações: O Windows 10 e 11 centralizaram a maioria das configurações no aplicativo "Configurações" (Windows + I), mas o Painel de Controle clássico ainda existe.

Contas de Usuário

O Windows permite diferentes tipos de contas:

  • Administrador: Tem controle total do computador. Pode instalar programas, alterar configurações e gerenciar outros usuários.
  • Usuário Padrão: Pode usar os programas, mas não pode instalar softwares ou alterar configurações que afetem outros usuários ou a segurança do sistema.
  • Conta de Convidado: Acesso limitado e temporário (desativada por padrão em versões mais recentes).
⚠️ Pegadinha FAFIPA: O Windows Update é a ferramenta oficial de atualização da Microsoft. A banca vai tentar dizer que o Windows Update é um antivírus ou um limpador de disco. Ele apenas gerencia as atualizações de segurança e do sistema.

2. Linux Ubuntu

O Linux é um sistema operacional de código aberto (open source), o que significa que seu código-fonte é público e pode ser modificado por qualquer pessoa. O Ubuntu é uma das distribuições (versões) mais populares do Linux.

Características do Linux

  • Código Aberto: Gratuito e modificável.
  • Multiusuário e Multitarefa: Vários usuários podem usar ao mesmo tempo, e vários programas podem rodar simultaneamente.
  • Interface Gráfica (GNOME no Ubuntu): O Ubuntu possui interface gráfica amigável, mas o coração do sistema é o Terminal.
  • Usuário Root: É o "superusuário" do Linux, equivalente ao Administrador do Windows. Tem poder total sobre o sistema.
  • Sistema de Arquivos: O Linux não usa letras de unidade (C:, D:). Ele usa uma estrutura de diretórios em árvore, começando pela raiz "/".

Comandos Básicos do Terminal Linux

A FAFIPA pode cobrar o significado de alguns comandos. Decore os principais:

Comando Função
lsListar arquivos e pastas (equivalente ao "dir" no Windows).
cdMudar de diretório (Change Directory).
pwdMostra o caminho do diretório atual (Print Working Directory).
mkdirCriar uma nova pasta (Make Directory).
rmRemover arquivos (Remove).
cpCopiar arquivos (Copy).
mvMover ou renomear arquivos (Move).

💡 Dicas de Ouro para a Prova

⚠️ O que a FAFIPA adora cobrar:

  • Linux é código aberto: Não é pago. O Windows é proprietário e pago.
  • Usuário Root: É o administrador do Linux. A banca vai tentar chamar de "Administrador" ou "Superusuário".
  • Sistema de arquivos: O Windows usa letras (C:, D:). O Linux usa uma árvore única com a raiz "/".
  • Comandos Linux: ls = listar, cd = mudar de pasta, mkdir = criar pasta, rm = remover.
  • Windows Update: É a ferramenta de atualização do Windows. Não é antivírus.
  • Ubuntu: É uma distribuição Linux. A banca pode perguntar se o Ubuntu é um sistema operacional (sim) ou uma distribuição do Linux (sim).
