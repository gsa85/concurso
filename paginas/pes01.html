1. Conceitos Básicos

Antes de tudo, é preciso diferenciar três termos que a banca adora misturar:

  • Método: É o caminho, a lógica, a forma de raciocinar para chegar ao conhecimento. É o "como pensar".
  • Técnica: É o instrumento, a ferramenta utilizada para coletar os dados. É o "como fazer".
  • Pesquisa: É o conjunto de ações que visa resolver um problema ou descobrir algo novo, utilizando o método e as técnicas.
Método = Caminho | Técnica = Ferramenta | Pesquisa = Ação

2. Tipos de Pesquisa (Classificação)

Quanto à Natureza

  • Pesquisa Básica (Pura): Objetiva gerar conhecimentos novos para o avanço da ciência, sem aplicação prática prevista. Ex: descobrir uma nova partícula.
  • Pesquisa Aplicada: Objetiva gerar conhecimentos para aplicação prática, resolvendo problemas concretos. Ex: criar uma vacina.

Quanto à Abordagem

  • Qualitativa: Foca na qualidade, na subjetividade, nos significados. Não usa números. Ex: entrevista sobre sentimentos.
  • Quantitativa: Foca na quantidade, nos números, nas estatísticas. Traduz em números as opiniões. Ex: censo populacional.

Quanto aos Objetivos

  • Exploratória: Tem a finalidade de proporcionar maior familiaridade com o problema, torná-lo mais explícito. É a primeira pesquisa sobre um tema (pouco conhecido).
  • Descritiva: Objetiva descrever as características de uma população ou fenômeno. Ex: censo do IBGE (idade, sexo, renda).
  • Explicativa: Objetiva identificar os fatores que determinam ou contribuem para a ocorrência de um fenômeno. Explica o "porquê" das coisas.

Quanto aos Procedimentos

  • Pesquisa Bibliográfica: Baseada em livros, artigos, teses já publicados.
  • Pesquisa Documental: Baseada em documentos que não receberam tratamento analítico (jornais antigos, cartas, arquivos).
  • Pesquisa Experimental: O pesquisador manipula as variáveis para testar uma hipótese.
  • Estudo de Caso: Estudo profundo de um ou poucos objetos, de forma detalhada.
  • Levantamento (Survey): Interrogação direta das pessoas para obter dados (ex: questionário em massa).
  • Pesquisa-Ação: O pesquisador e os participantes estão envolvidos de modo cooperativo, visando a resolução de um problema prático.
  • Pesquisa Participante: O pesquisador se envolve na realidade do grupo, mas sem a mesma ênfase na ação de transformação da Pesquisa-Ação.
⚠️ Pegadinha FAFIPA: A Pesquisa **Exploratória** é a primeira sobre um tema pouco conhecido. A Pesquisa **Descritiva** apenas descreve (não explica). A Pesquisa **Explicativa** é a mais profunda, pois busca o "porquê". A banca vai tentar trocar as definições.

3. Métodos Científicos (Raciocínio)

Método Dedutivo

Parte do geral para o específico. Usa a lógica e a dedução. Se a premissa maior for verdadeira, a conclusão é necessariamente verdadeira.

Exemplo: Todo ser humano é mortal (premissa geral). João é humano. Logo, João é mortal (conclusão específica).

Método Indutivo

Parte do específico para o geral. Usa a observação de casos particulares para chegar a uma regra geral.

Exemplo: O cobre conduz eletricidade. O ferro conduz. O ouro conduz. Logo, todos os metais conduzem eletricidade (regra geral).

Método Hipotético-Dedutivo

Parte de uma hipótese que deve ser testada e falseada. É o método da ciência moderna (Popper). Não se busca provar que a hipótese é verdadeira, mas sim testar se ela se sustenta diante das evidências.

Método Dialético

Baseia-se na contradição e na mudança. Utiliza a tríade: Tese → Antítese → Síntese.

⚠️ Pegadinha FAFIPA: A regra é clara: Dedutivo = Geral para Específico. Indutivo = Específico para Geral. A banca vai inverter as definições para te confundir.

4. Técnicas de Coleta de Dados

Questionário

  • É um instrumento escrito.
  • O pesquisador não precisa estar presente.
  • Pode ser aplicado a um grande número de pessoas (economia de tempo).
  • Pode ser enviado por e-mail ou entregue pessoalmente.

Entrevista

  • É um instrumento oral.
  • O pesquisador está presente (interação face a face).
  • Permite observar reações e aprofundar respostas.
  • É mais trabalhosa e demorada.

Observação

  • O pesquisador observa o comportamento ou fenômeno diretamente.
  • Pode ser participante (o pesquisador se envolve) ou não participante (apenas observa).

Análise Documental

  • Uso de documentos (leis, arquivos, jornais) para obter dados.
⚠️ Pegadinha FAFIPA: Questionário é escrito e não precisa do pesquisador. Entrevista é oral e o pesquisador está presente. A banca vai trocar "escrito" por "oral" nas alternativas.

💡 Dicas de Ouro para a Prova

⚠️ O que a FAFIPA adora cobrar:

  • Indução vs. Dedução: Decore: Indutivo = Individual (específico) para o geral. Dedutivo = De uma regra geral para o específico.
  • Pesquisa Básica vs. Aplicada: A básica gera conhecimento puro (sem aplicação imediata). A aplicada resolve problemas práticos.
  • Exploratória vs. Descritiva: Exploratória é para temas novos. Descritiva é para descrever o que já existe (censo).
  • Questionário vs. Entrevista: Questionário = escrito e sem contato. Entrevista = oral e com contato.
  • Pesquisa-Ação vs. Participante: A Pesquisa-Ação tem um caráter mais ativo e transformador (intervenção). A Pesquisa Participante é mais de inserção no grupo.
