1. O que é um Navegador de Internet?

O navegador (browser) é um software aplicativo que permite ao usuário acessar e visualizar páginas da internet. Ele interpreta o código HTML, CSS e JavaScript das páginas e as transforma em conteúdo visual.

Importante: o navegador não é a internet. A internet é a infraestrutura de rede; o navegador é apenas a ferramenta que usamos para acessá-la.

Internet = Infraestrutura (rede mundial)
Navegador = Ferramenta (software para acessar a web)

3. Funcionalidades dos Navegadores

Abas (Tabs)

Permitem abrir várias páginas na mesma janela. Atalhos: Ctrl + T (nova aba), Ctrl + W (fechar aba), Ctrl + Tab (alternar entre abas).

Favoritos / Favoritos (Bookmarks)

Permitem salvar endereços de páginas para acessar rapidamente depois. Atalho: Ctrl + D (adicionar aos favoritos).

Histórico

Registra todas as páginas visitadas. Pode ser acessado pelo atalho Ctrl + H.

Downloads

Gerencia os arquivos baixados da internet. Atalho: Ctrl + J.

Barra de Endereços (URL)

Local onde digitamos o endereço do site (ex: www.google.com). Também funciona como campo de busca, dependendo da configuração do navegador.

Modo Anônimo / Navegação Privada

Navega sem salvar histórico, cookies e dados de formulários. Não torna o usuário invisível na internet! Apenas não deixa rastros no computador local.

⚠️ Pegadinha FAFIPA: O Modo Anônimo NÃO torna o usuário invisível na internet. Ele apenas não salva histórico, cookies e senhas no computador local. O provedor de internet e os sites visitados ainda podem rastrear o acesso!

4. Segurança e Privacidade nos Navegadores

Cookies

São pequenos arquivos de texto que os sites armazenam no computador do usuário para lembrar preferências (ex: idioma, login). Podem ser usados para rastreamento e publicidade.

Cache

É o armazenamento temporário de partes das páginas (imagens, vídeos, scripts) para acelerar o carregamento. Limpar o cache libera espaço e força o navegador a baixar versões atualizadas das páginas.

Certificado Digital / HTTPS

O cadeado na barra de endereços (HTTPS) indica que a conexão é criptografada. Não garante que o site seja confiável, mas garante que a comunicação é segura.

Bloqueador de Pop-ups

Recurso que impede a abertura automática de janelas indesejadas (pop-ups).
