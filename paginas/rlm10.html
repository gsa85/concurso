1. Sequências Numéricas

O objetivo é descobrir a regra (lógica) que rege os números e, a partir dela, descobrir o próximo termo. As regras mais comuns são:

Soma ou Subtração Constante

Você soma ou subtrai sempre o mesmo valor.

Exemplo: 2, 5, 8, 11, 14... (A regra é "somar 3").

Multiplicação ou Divisão

Os números crescem ou diminuem de forma multiplicativa.

Exemplo: 3, 6, 12, 24, 48... (A regra é "multiplicar por 2").

Sequência de Fibonacci

Cada número é a soma dos dois anteriores.

Exemplo: 1, 1, 2, 3, 5, 8, 13... (1+1=2; 1+2=3; 2+3=5; 3+5=8...).

Números Primos

Sequência de números que só são divisíveis por 1 e por eles mesmos.

Exemplo: 2, 3, 5, 7, 11, 13, 17...

2. Sequências de Letras

Para resolver sequências de letras, você precisa ter em mente a posição de cada letra no alfabeto (A=1, B=2, C=3... Z=26). A banca costuma cobrar três tipos de padrões:

Pular Letras de Forma Constante

Exemplo: A, C, E, G, I... (Pula 1 letra sempre).

Exemplo: B, F, J, N, R... (Pula 3 letras sempre: B->C,D,E->F).

Alfabeto Invertido

A sequência começa do Z e vai voltando.

Exemplo: Z, X, V, T, R... (Volta 2 letras sempre).

Vogais e Consoantes Separadas

Às vezes, a banca mistura, mas a regra é apenas para as vogais ou apenas para as consoantes.

Exemplo: A, B, E, D, I, F, O... (Vogais seguem a ordem A, E, I, O; Consoantes seguem B, D, F).

Dica: Escreva o alfabeto no rascunho e numere de 1 a 26!

3. Sequências de Figuras

Esse é o tipo de questão que exige mais atenção visual. As regras mais comuns envolvem:

  • Rotação: A figura gira 90º ou 180º para a direita ou esquerda.
  • Quantidade de lados: Triângulo (3 lados) -> Quadrado (4) -> Pentágono (5) -> Hexágono (6).
  • Preenchimento: A figura alterna entre vazada e preenchida (colorida).
  • Movimentação de elementos: Um pontinho que se move para cima, para baixo ou para os lados dentro da figura.

💡 Dicas de Ouro para a Prova

⚠️ O que a FAFIPA adora cobrar:

  • Sequências Alternadas (Intercaladas): A banca coloca duas regras ao mesmo tempo. Ex: 2, 10, 4, 20, 6, 30... (Os números ímpares somam 2; os pares multiplicam por 10). Sempre olhe pulando de 2 em 2!
  • Posição das Letras: Decore o início do alfabeto (A=1, B=2, C=3...). Se a sequência for E, G, I..., pense nos números (5, 7, 9).
  • Figuras com números de lados: Se aparecer um triângulo, quadrado, pentágono, a próxima figura é um hexágono (6 lados).
  • Não complique: A regra geralmente é simples. Se você está fazendo cálculos complexos (ex: potências de 3 com raiz quadrada), provavelmente está no caminho errado.

5. Teste seus Conhecimentos (FAFIPA)

1. Qual é o próximo número da sequência: 3, 7, 11, 15, ...?

2. Na sequência de Fibonacci: 1, 1, 2, 3, 5, 8, ..., qual é o próximo número?

3. Qual é a próxima letra da sequência: B, D, F, H, ...?

4. Observe a sequência intercalada: 2, 10, 4, 20, 6, 30, 8, ... Qual é o próximo número?

5. Em uma sequência de figuras geométricas, aparecem respectivamente: um Triângulo (3 lados), um Quadrado (4 lados) e um Pentágono (5 lados). Seguindo o padrão, qual é a próxima figura?

6. (Extra) Qual é o próximo termo da sequência: 1, 4, 9, 16, 25, ...?
