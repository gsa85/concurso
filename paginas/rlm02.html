1. Comparações de Números

Comparar números significa dizer se um é maior (>), menor (<) ou igual (=) a outro.

Números Decimais

Para comparar números com vírgula, iguale a quantidade de casas decimais (adicionando zeros à direita) e compare como se fossem números inteiros.

  • Exemplo: Comparar 0,5 e 0,05.
    Igualando as casas: 0,50 e 0,05.
    Como 50 > 05, então 0,5 > 0,05.

Números Negativos

Aqui mora a maior pegadinha! Em números negativos, o que tem o maior valor absoluto (sem o sinal) é o menor número.

  • Exemplo: Quem é maior, -10 ou -2?
    Pense na reta numérica: -10 está mais para a esquerda. Portanto, -10 < -2.

Frações

Se os denominadores (números de baixo) forem iguais, a maior fração é a que tem o maior numerador (número de cima). Ex: 3/5 > 2/5.

Se os denominadores forem diferentes, você pode transformá-los em decimais (dividindo) ou tirar o MMC.

2. Arredondamentos

Arredondar é simplificar um número para uma quantidade menor de casas decimais, mantendo-o próximo do valor real.

A Regra de Ouro do Arredondamento

Para arredondar, você olha para o primeiro algarismo que será descartado (o número imediatamente à direita da casa que você quer manter):

  • Se o algarismo for 0, 1, 2, 3 ou 4: você mantém o número anterior como está. (Arredonda para baixo)
  • Se o algarismo for 5, 6, 7, 8 ou 9: você aumenta em 1 unidade o número anterior. (Arredonda para cima)

Exemplos:

  • Arredondar 4,38 para uma casa decimal: O número a ser descartado é o 8 (maior que 5). Então o 3 aumenta: 4,4.
  • Arredondar 7,21 para uma casa decimal: O número a ser descartado é o 1 (menor que 5). Então o 2 se mantém: 7,2.
⚠️ Pegadinha FAFIPA: Quando o algarismo a ser descartado for exatamente 5, a regra matemática padrão manda arredondar para cima. Exemplo: 3,5 arredondado para inteiro vira 4. Mas fique atento se o edital citar regras específicas de instituições (como o IBGE, que em alguns casos usa o "arredondamento bancário" para números pares). Para a FAFIPA, use a regra do "5 para cima".

3. Aproximações e Estimativas

Na prova, muitas vezes você não precisa fazer a conta exata. Você pode estimar o resultado arredondando os números para valores mais fáceis.

Exemplo prático: Quanto é 48 × 21?

  • Fazendo a conta exata: 1.008.
  • Estimando: Arredonda 48 para 50, e 21 para 20. Multiplicando 50 × 20 = 1.000.
  • Veja que a estimativa (1.000) é muito próxima do valor real (1.008). Em questões de múltipla escolha, se as alternativas forem muito distantes umas das outras, a estimativa te leva direto para a resposta certa sem você precisar fazer a conta completa.

Ordem de Grandeza: Às vezes a banca pede apenas a "potência de 10" mais próxima. Ex: 9.800 é da ordem de 10.000 (104).

💡 Dicas de Ouro para a Prova

⚠️ O que a FAFIPA adora cobrar:

  • Números Negativos: A banca vai colocar -15 e -3 e perguntar qual é o menor. O -15 é o menor! Pense sempre na reta numérica (quanto mais para a esquerda, menor).
  • Zeros após a vírgula: 0,3 é MAIOR que 0,299. Muitos candidatos acham que 299 é maior que 3, mas 0,3 = 0,300, que é maior que 0,299.
  • Arredondamento de 5: Se precisar arredondar 8,5 para inteiro, a resposta é 9 (regra do 5 para cima).
  • Estimativa em múltipla escolha: Antes de fazer contas gigantes, olhe as alternativas. Se a A for 10, B for 1.000, C for 100.000, você só precisa estimar a "ordem de grandeza" para acertar.
