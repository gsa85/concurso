1. Arquivos e Pastas

O que é um Arquivo?

É um conjunto de informações armazenadas em um dispositivo (HD, SSD, Pen Drive). Pode ser um texto, uma foto, um vídeo, um programa.

O que é uma Pasta (Diretório)?

É um local onde organizamos os arquivos. As pastas podem conter outras pastas (subpastas) e arquivos. No Windows, a pasta principal de um usuário é a "Documentos", "Imagens", "Downloads", etc.

Atalhos vs. Cópia

  • Atalho: É um ícone (com uma pequena seta) que aponta para o arquivo original. Ele não ocupa espaço significativo. Se você apagar o atalho, o arquivo original continua lá.
  • Cópia: É uma duplicata do arquivo. Ocupa espaço em disco e é independente do original.

2. Extensões de Arquivos (O que mais cai!)

A extensão é a parte final do nome do arquivo, após o ponto. Ela indica qual programa deve ser usado para abrir o arquivo.

⚠️ Pegadinha FAFIPA: O arquivo .exe é um executável (instala ou roda um programa). Já o arquivo .zip ou .rar é um arquivo compactado (precisa ser descompactado). A banca vai trocar as definições.

3. Lixeira e Exclusão de Arquivos

Ao excluir um arquivo no Windows, ele vai para a Lixeira, onde pode ser restaurado. Mas nem tudo vai para a lixeira!

O que NÃO vai para a Lixeira:

  • Arquivos excluídos de Pen Drives ou HDs Externos.
  • Arquivos excluídos de redes (servidores).
  • Arquivos excluídos com Shift + Delete (exclusão permanente).
  • Arquivos maiores que o limite da lixeira.

Como restaurar um arquivo?

Abra a Lixeira, clique com o botão direito no arquivo e escolha "Restaurar". Ele voltará para o local original.

💡 Dicas de Ouro para a Prova

⚠️ O que a FAFIPA adora cobrar:

  • Lixeira: Arquivos de Pen Drive não vão para a Lixeira. Eles são excluídos permanentemente.
  • Shift + Delete: Exclui o arquivo permanentemente, sem passar pela Lixeira.
  • Arrastar e Soltar: Se você arrastar um arquivo para outra pasta no mesmo disco, ele é movido. Se arrastar para outro disco (ex: do HD para o Pen Drive), ele é copiado.
  • Extensão .exe: É um arquivo executável. A banca vai dizer que é um arquivo de texto ou compactado.
  • Atalho: É representado por um ícone com uma seta. Não é o arquivo original.
