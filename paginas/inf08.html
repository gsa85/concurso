2. Formatação de Fonte (Aba Página Inicial)

As principais ferramentas de formatação de texto ficam na aba Página Inicial:

  • Negrito (N): Destaca o texto em negrito. Atalho: Ctrl + N.
  • Itálico (I): Deixa o texto em itálico. Atalho: Ctrl + I.
  • Sublinhado (S): Sublinha o texto. Atalho: Ctrl + S (no Word, Ctrl+S é sublinhar; salvar é Ctrl+B).
  • Tamanho da Fonte: Altera o tamanho do texto. Atalho: Ctrl + Shift + P.
  • Aumentar/Diminuir Fonte: Ctrl + Shift + > (aumenta) e Ctrl + Shift + < (diminui).
  • Cor da Fonte: Altera a cor do texto.
  • Maiúsculas e Minúsculas: Altera a capitalização do texto (tudo maiúsculo, tudo minúsculo, etc.). Atalho: Shift + F3.
  • Limpar Formatação: Remove toda a formatação do texto selecionado, deixando-o no padrão.
⚠️ Pegadinha FAFIPA: No Word, o atalho Ctrl+S é para Sublinhar, e não para Salvar! O atalho para Salvar no Word é Ctrl+B (de "Baixar" ou do inglês "Save" que não é usado). Já no Windows, Ctrl+S é Salvar. A banca vai tentar confundir!

3. Formatação de Parágrafo (Aba Página Inicial)

As ferramentas de parágrafo também ficam na aba Página Inicial:

  • Alinhamento:
    • Esquerda: Texto alinhado à margem esquerda. Atalho: Ctrl + Q.
    • Centralizado: Texto no centro. Atalho: Ctrl + E.
    • Direita: Texto alinhado à margem direita. Atalho: Ctrl + G.
    • Justificado: Texto alinhado às duas margens. Atalho: Ctrl + J.
  • Espaçamento entre Linhas: Define o espaço entre as linhas do texto.
  • Marcadores e Numeração: Cria listas com marcadores (bolinhas) ou numeradas.
  • Recuo: Aumenta ou diminui o recuo do parágrafo em relação à margem.

4. Mala Direta (Aba Correspondências)

A Mala Direta é uma das ferramentas mais cobradas da FAFIPA. Ela serve para criar um documento modelo e combinar com uma lista de dados (como uma planilha do Excel) para gerar vários documentos personalizados.

Exemplo prático:

Imagine que você quer enviar uma carta para 100 clientes, mas cada carta precisa ter o nome e o endereço de cada um. Em vez de digitar 100 cartas, você faz:

  1. Cria o texto base (o modelo da carta).
  2. Conecta uma lista de dados (ex: uma planilha do Excel com nomes e endereços).
  3. Insere os "campos de mesclagem" (nome, endereço) no texto.
  4. O Word gera automaticamente as 100 cartas personalizadas.

Onde fica?

A ferramenta Mala Direta fica na aba Correspondências.

⚠️ Pegadinha FAFIPA: A Mala Direta não fica na aba "Inserir" nem na "Revisão". Ela fica na aba Correspondências. A banca vai tentar trocar a aba!

💡 Dicas de Ouro para a Prova

⚠️ O que a FAFIPA adora cobrar:

  • Mala Direta: Fica na aba Correspondências. Serve para personalizar documentos em massa.
  • Ctrl+S no Word: É Sublinhar (não Salvar). Salvar é Ctrl+B.
  • Ctrl+Shift+P: Altera o tamanho da fonte.
  • Shift+F3: Alterna Maiúsculas/Minúsculas.
  • Alinhamento Justificado: Atalho Ctrl+J.
  • F12: Abre a janela Salvar Como.
  • Quebra de Página: Atalho Ctrl+Enter.
  • Contar Palavras: Fica na aba Revisão.
