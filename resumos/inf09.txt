 Planilhas Eletrônicas: Excel 2016
Software para cálculos, organização de dados e gráficos. O essencial é dominar as fórmulas e funções básicas.

Início de Fórmula: Toda fórmula começa com o sinal de igual =.

Funções Mais Cobradas:

=SOMA(intervalo) → Soma os valores.

=MÉDIA(intervalo) → Calcula a média.

=MÁXIMO(intervalo) / =MÍNIMO(intervalo) → Retorna o maior/menor valor.

Referência Absoluta: Usa o cifrão para fixar a célula (ex.: $A$1). A referência relativa (A1) se ajusta ao copiar a fórmula.

A FAFIPA já cobrou o atalho para inserir a função Soma automaticamente (AutoSoma), que é Alt + =.
