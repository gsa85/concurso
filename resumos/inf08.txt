Processador de Texto: Word 2016
Software para criar e editar documentos de texto. O foco da FAFIPA está nos atalhos de formatação e comandos de arquivo.

Atalhos de Formatação:

Ctrl + N → Negrito

Ctrl + I → Itálico

Ctrl + S → Sublinhado

Ctrl + J → Justificar

Outros Atalhos:

Ctrl + A → Selecionar todo o texto.

Ctrl + P → Imprimir.

Ctrl + F4 → Fechar o documento (a banca já cobrou este atalho específico).

Pegadinha: A banca pode pedir a sequência de atalhos para "selecionar tudo, colocar negrito e imprimir", que seria Ctrl + A, Ctrl + N, Ctrl + P.
